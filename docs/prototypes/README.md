# 产品体验 HTML 原型

`docs/prototypes/product-experience.html` 是产品体验事实源。

它用于验证：

- 页面关系
- 用户路径
- 对象归属
- 入口流向

它不代表正式 React 组件结构，不定义 API / DB / contracts，不实现真实 Agent Run。

正式实现仍需遵守：

- `AGENTS.md`
- `docs/ui-design.md`
- `docs/architecture.md`
- `docs/contracts.md`
- `packages/contracts/*`

这个原型只使用单文件 HTML、CSS 和少量原生 JavaScript，用来说明：

- 产品怎么用
- 页面怎么跳
- 哪个页面承载什么
- 哪个页面只展示摘要 / 入口

打开方式：直接在浏览器中打开 `docs/prototypes/product-experience.html`。
