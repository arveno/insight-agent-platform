# Scripts

本目录承载项目自动化和运维脚本入口。

固定目录：

- `verify/`：全局质量检查入口。
- `build/`：构建入口。
- `package/`：发布产物打包入口。
- `deploy/`：部署执行入口。
- `rollback/`：回滚入口。
- `migration/`：数据库 migration / seed 执行入口。
- `contracts/`：契约与结构检查入口。
- `smoke/`：Smoke Test 入口。
- `load/`：Load Test 入口。
- `failure-simulation/`：故障模拟入口。
- `security/`：安全检查入口。

当前阶段只建立承载位，不写真实业务脚本。
